# Анализ данных GPS-телеметрии

## Описание задачи

Разработать скрипт для анализа данных GPS-телеметрии транспортных средств для автоматизации отчётности по пробегу и топливу. 
Исходные данные — Excel-файл с двумя листами:
- **GPS_данные** — телеметрия (ТС, дата/время, координаты, скорость, обороты, уровень топлива)
- **Нормативы** — справочник норм расхода топлива по режимам (город/трасса/холостой ход)

## Основные этапы

1. **Очистка данных** — удаление пропусков, дубликатов, приведение типов
2. **Преобразование координат** — формат `градусы° минуты'` → десятичные градусы
3. **Расчёт пробега** — формула гаверсинуса, дневной пробег, средняя скорость
4. **Анализ расхода топлива** — режимы работы, типы трассы, расход за интервал
5. **Выявление аномалий** — отклонение расчётного расхода от фактического >30%
6. **Поиск оптимальной скорости** — интервалы по 5 км/ч, минимальный часовой расход
7. **Анализ холостого хода** — время простоя, перерасход топлива
8. **Автоматизация** — единый скрипт с сохранением результатов в Excel

## Используемые технологии

- Python 3
- Pandas, NumPy
- Matplotlib
- OpenPyXL (для работы с Excel)

## Результаты

- Итоговый Excel-файл с листами: *Сводка по ТС*, *Детализация*, *Аномалии*
- Выявлены 2 аномалии с отклонением >30%
- Определена оптимальная скорость — 80–85 км/ч (12,7 л/час)
- Найдена машина-рекордсмен по холостому ходу — 5,72 часа, перерасход 14,87 л
