# ETL-скрипт для загрузки и очистки данных

## Что делает скрипт

- **Извлечение** данных из файлов форматов CSV, JSON, Excel, XML.
- **Приведение к единому формату**: преобразование типов, обработка пропусков, удаление дубликатов.
- **Логирование ошибок** с сохранением проблемных записей для анализа качества данных.
- **Загрузка** подготовленных данных в базу данных.


## Используемые технологии
- **Python**
- **Pandas** – для обработки и анализа данных
- **SQLAlchemy** – для подключения к базе данных
- **SQLite** – как целевое хранилище
