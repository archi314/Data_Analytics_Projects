# Проект: Построение хранилища данных (DWH) на основе данных из 5 разнородных источников

## Описание проекта

В рамках проекта были выполнены следующие этапы:

1. **Загрузка данных в pandas** из 5 разнородных источников:  
   - `customers.csv`  
   - `orders.json`  
   - `products.xlsx`  
   - `events.xml`  
   - `payments.csv`

2. **Приведение данных к единому формату**:  
   - Преобразование типов данных.  
   - Обработка пропусков.  
   - Удаление явных и неявных дубликатов.  
   - Удаление лишних пробелов.
   - Загрузка данных в БД

3. **Обработка ошибок и логирование**:  
   - Все проблемные записи залогированы в таблицу `error_log` (или CSV-файл).  

4. **Построение DWH-модели (Star Schema)**:  
   - Измерения: `dim_customers`, `dim_products`, `dim_dates`, `dim_event_types`.  
   - Факты: `fact_orders`, `fact_payments`, `fact_events`.  
   - Модель реализована в SQLite (файл `dwh.db`, `dwh.sql`).

5. **Аналитические SQL-запросы на основе построенной DWH-модели**:  
   - Топ-10 клиентов по сумме покупок.  
   - Выручка по месяцам.  
   - Самые популярные товары.  
   - Последняя активность топ-5 покупателей.  
   - Пользователи без заказов.
