## Построение DWH-модели (Star Schema)

Файл `dwh.sql` содержит SQL-скрипт для создания хранилища данных в **Star Schema** на основе ранее очищенных таблиц.

### Структура модели

**Измерения (справочники):**
- `dim_customers` – информация о клиентах
- `dim_products` – информация о товарах
- `dim_dates` – календарь дат (для временных срезов)
- `dim_event_types` – типы событий пользователей

**Факты (события, метрики):**
- `fact_orders` – заказы (связь с клиентами, товарами, датами, сумма заказа)
- `fact_payments` – платежи (связь с заказами, клиентами, датами, сумма и способ оплаты)
- `fact_events` – события пользователей (связь с клиентами, типом события, датой)

Все таблицы создаются в базе данных SQLite (`dwh.db`).
