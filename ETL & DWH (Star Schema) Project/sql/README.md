## Аналитические запросы

Файл содержит готовые аналитические запросы к построенной DWH-модели:

| Запрос | Описание |
|--------|----------|
| **Топ-10 клиентов по сумме покупок** | Клиенты с наибольшей общей суммой заказов |
| **Выручка по месяцам** | Динамика продаж по месяцам (год, месяц, сумма) |
| **Самые популярные товары** | Товары по количеству заказов |
| **Последняя активность топ-5 покупателей** | Дата последнего события для клиентов с наибольшей выручкой |
| **Пользователи без заказов** | Клиенты, у которых нет ни одного заказа |

Все запросы используют таблицы `fact_orders`, `dim_customers`, `dim_products`, `dim_dates` и `dim_event_types`.
